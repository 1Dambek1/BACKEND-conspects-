# Конспекты по backend-разработке

Здесь собраны краткие конспекты по основным темам backend-разработки на Python.

## Содержание

- [FastAPI — основы](<FastAPI — основы.md>) — создание API, методы GET/POST/PUT, роутеры, зависимости, Pydantic и HTTP-статусы.
- [SQL — основы](<SQL — основы.md>) — таблицы, добавление, поиск, изменение и удаление данных.
- [SQL — связи между таблицами](<SQL — связи между таблицами.md>) — связи один-к-одному, один-ко-многим и многие-ко-многим с SQL-примерами.
- [SQLAlchemy — основы](<SQLAlchemy — основы.md>) — работа с SQLite и SQL из Python через модели и сессии.
- [SQLAlchemy — связи и загрузка](<SQLAlchemy — связи и загрузка.md>) — `relationship()`, модель-связка и загрузка связанных данных через `selectinload()`.
- [Git и GitHub — основы](<Git и GitHub — основы.md>) — репозитории, коммиты, ветки и основные команды.
- [Асинхронность и многопоточность — основы](<Асинхронность и многопоточность — основы.md>) — `asyncio`, потоки и примеры на задачах ресторана.
- [Asyncio — задачи, лимиты и очереди](<Asyncio — задачи, лимиты и очереди.md>) — `gather`, `as_completed`, `Semaphore`, `wait_for`, `Lock` и `Queue`.

Новые темы будут добавляться отдельными файлами.
