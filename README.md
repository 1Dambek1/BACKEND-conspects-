# Конспекты по backend-разработке

Здесь собраны краткие конспекты по основным темам backend-разработки на Python.

## Содержание

- [FastAPI — основы](<FastAPI — основы.md>) — создание API, методы GET/POST/PUT, роутеры, зависимости, Pydantic и HTTP-статусы.
- [SQL — основы](<SQL — основы.md>) — таблицы, добавление, поиск, изменение и удаление данных.
- [SQLAlchemy — основы](<SQLAlchemy — основы.md>) — работа с SQLite и SQL из Python через модели и сессии.

Новые темы будут добавляться отдельными файлами.
